# Processo de Criação de Conteúdo

## Processo em 6 passos (por peça)

1. Definir pilar
2. Identificar dor
3. Definir resultado esperado
4. Criar hook
5. Estruturar conteúdo
6. Definir CTA

## Pipeline de 8 etapas (operacional)

1. IDEIA → Agente Ideator
2. SELEÇÃO → Estrategista
3. ROTEIRO → Agente Copywriter
4. REFINAMENTO → Agente Analista
5. PRODUÇÃO → Canva
6. POST → Instagram
7. MÉTRICA → Notion
8. AJUSTE → Analista + Estrategista

## Fluxo semanal

| Dia | Ação |
|-----|------|
| Segunda | Ideação + seleção (3 ideias) |
| Terça | Roteiro + refinamento |
| Quarta | Produção visual (Canva) |
| Quinta | Revisão final + agendamento |
| Sexta | Post principal |
| Sábado | Post secundário ou reels |
| Domingo | Análise da semana |

## Convenção de commits (Git)

```
feat: novo conteúdo criado
refactor: melhoria em conteúdo existente
repurpose: adaptação de formato
fix: correção de erro
chore: atualização de backlog
```

## Nomenclatura de arquivos

```
posts/YYYY-MM-DD-[pilar]-[formato].md
reels/roteiro-[tema]-[número].md
stories/stories-[tema]-[número].md
```
