# Processo de Reaproveitamento

## Regra principal

Nenhum conteúdo é usado apenas uma vez.

Sempre adaptar para:
- vídeo
- texto
- sequência

## Matriz de repurpose

| Original | → Formato 1 | → Formato 2 | → Formato 3 |
|----------|-------------|-------------|-------------|
| Carrossel | Reels (narrado) | Texto (feed) | Stories (sequência) |
| Reels | Carrossel (expandido) | Texto (reflexão) | Quote |
| Texto | Carrossel (visual) | Reels (leitura) | Stories (pergunta) |

## Critério para repurpose

Só reaproveitar conteúdo que:
- Salvamentos > média da conta
- Comentários com "salvei" ou "anotei"
- Alcance > 2x a média

## Processo

1. Identificar conteúdo de alto desempenho (Notion)
2. Definir novo formato e objetivo
3. Rodar Agente de Repurpose (prompts/conversao.md)
4. Produzir com Canva
5. Agendar com intervalo mínimo de 30 dias do original

## Commit

```
repurpose: [tema] - [original] para [novo formato]
```
