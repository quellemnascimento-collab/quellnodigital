# QuellnoDigital OS

Sistema operacional da marca @quellnodigital

## Objetivo
Transformar experiência de gestão em autoridade digital estruturada,
utilizando IA, sistemas e conteúdo estratégico.

## Estrutura

- core → identidade da marca
- prompts → inteligência operacional
- conteudo → produção
- flux → produto e monetização
- processos → execução
- referencias → base estratégica

## Regra principal

Conteúdo não é criatividade.
Conteúdo é sistema.

## Fluxo

IDEIA → ROTEIRO → PRODUÇÃO → POST → REAPROVEITAMENTO

## Uso com IA

Todos os prompts estão na pasta /prompts
Devem ser usados com Claude, Manus ou ChatGPT
