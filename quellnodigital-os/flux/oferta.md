# Oferta

## Estrutura de oferta

### Topo (captação de lead)
- Formato: [ebook / aula grátis / template / checklist]
- Entrega: [link / DM / stories]
- Objetivo: entrar na lista

### Meio (nutrição)
- Formato: [sequência de e-mails / stories / conteúdo exclusivo]
- Duração: ___ dias
- Objetivo: gerar confiança + intenção

### Fundo (venda)
- Oferta principal: [nome do produto]
- Prazo: [lançamento / evergreen]
- CTA: [link / DM / grupo]

## Gatilhos utilizados
- Prova social: ✓
- Escassez real: ✓
- Autoridade: ✓
- Especificidade do resultado: ✓
