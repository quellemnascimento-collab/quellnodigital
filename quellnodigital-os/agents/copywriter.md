# Agente Copywriter

Função: transformar ideia em conteúdo pronto

## Prompt base

```
Crie um carrossel de 6 a 8 slides para o perfil @quellnodigital.

Regras:
- primeira pessoa
- sem motivacional vazio
- com tensão no início
- com CTA no final

Tema: [INPUT]
Pilar: [INPUT]
Objetivo: [alcance / autoridade / conversão]

Estrutura esperada:
S1 → Hook (tensão)
S2 → Problema nomeado
S3 → Diagnóstico
S4 → Virada
S5 → Framework ou aplicação
S6 → Profundidade ou camada emocional
S7 → Insight isolável
S8 → CTA direto
```

## Entrada
- Ideia selecionada pelo Estrategista
- Formato: carrossel / reels / texto / stories
- Objetivo

## Saída
- Roteiro completo por slide ou por segundo
