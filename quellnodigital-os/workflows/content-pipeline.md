# Workflow — Pipeline de Conteúdo

## Fluxo completo

```
IDEIA → SELEÇÃO → ROTEIRO → REFINAMENTO → PRODUÇÃO → POST → MÉTRICA → AJUSTE
  ↓         ↓         ↓           ↓             ↓        ↓       ↓         ↓
Ideator  Estrateg.  Copy      Analista       Canva    Insta   Notion   Loop ↺
```

## Etapas

| Etapa | Agente | Input | Output |
|-------|--------|-------|--------|
| 1. Ideia | Ideator | Dor + objetivo | 10 ideias ranqueadas |
| 2. Seleção | Estrategista | 10 ideias | 1 ideia + justificativa |
| 3. Roteiro | Copywriter | Ideia + formato | Roteiro completo |
| 4. Refinamento | Analista | Roteiro | Score + melhorias |
| 5. Produção | Canva | Roteiro aprovado | Arte final |
| 6. Post | Instagram | Arte + legenda | Publicação |
| 7. Métrica | Notion | Dados 7 dias | Diagnóstico |
| 8. Ajuste | Analista + Estrategista | Diagnóstico | Próximo ciclo |

## Backlog — Status
