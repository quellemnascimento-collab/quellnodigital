# Prompt — Carrossel

```
Crie um carrossel de 6 a 8 slides para o perfil @quellnodigital.

BRIEFING:
- Tema: [INPUT]
- Pilar: [IA na prática / Sistema vs improviso / Bastidor / Prova]
- Objetivo: [alcance / lead / conversão]

DNA DE ESCRITA:
- Primeira pessoa
- Tensão no início, sempre
- Resultado antes do processo
- Insight central em uma frase isolável

ESTRUTURA:
S1 → Hook (1-2 linhas. Para o scroll. Tensão.)
S2 → Tensão expandida (o problema real)
S3 → Diagnóstico (por que acontece)
S4 → Virada (o reframe)
S5 → Framework (o que fazer / como aplico)
S6 → Profundidade (camada emocional)
S7 → Insight isolável (a frase que vai ser salva)
S8 → CTA (ação direta e coerente com o funil)

REGRAS:
- Nunca começar com "Você sabia"
- Sem lista de dicas no início
- CTA coerente com a fase: [topo / meio / fundo]
```
