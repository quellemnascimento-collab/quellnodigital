# Prompt — Storytelling / Narrativa

```
Crie um conteúdo de narrativa para o perfil @quellnodigital.

FORMATO: [stories / texto longo / bastidor]

BRIEFING:
- Momento ou situação real: [INPUT]
- Aprendizado que gerou: [INPUT]
- Conexão com o público: [INPUT]

ESTRUTURA:
1. Cena (onde estava, o que aconteceu)
2. Conflito (o que não estava funcionando)
3. Virada (o momento de clareza)
4. Aplicação (o que mudou depois)
5. Insight para o público (o que isso significa para eles)
6. CTA (convite para se identificar ou agir)

REGRAS:
- Específico > genérico
- Cena antes de lição
- A lição emerge da história, não é declarada
- Tom: conversa, não palco

SE STORIES (5 telas):
T1 → Cena / gancho
T2 → Conflito
T3 → Virada
T4 → Insight
T5 → CTA ou pergunta aberta
```
